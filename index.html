Live market-data endpoints

  • EURUSD full analysis
  • EURUSD latest aggregated price
  • XAUUSD full analysis
  • NDX cash-index analysis

Data policy

  • Forex and supported non-crypto instruments: Twelve Data Grow 55 through the Cloudflare Worker.
  • Crypto execution data: exchange-native Binance / OKX / Bybit routes in GitHub Actions.
  • Cash indices, futures and spot metals are separate instruments and are never silently substituted for each other.
  • A freshly fetched aggregated price is not automatically an executable broker quote.
  • Bid/ask, spread and quote timestamp are reported only when actually verified.

Integrity

V73 development results are historical development evidence, not a live win-rate guarantee. V74 requires current context, structure and execution validation before MARKET decisions.
