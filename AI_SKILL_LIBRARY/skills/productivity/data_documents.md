# Skill: data_documents

Covers data analysis, spreadsheets, charts, reports, DOCX, PDF, slides/presentations, and Google Docs workflows.

- Inspect source schema/content before transforming it.
- Preserve raw data and create derived/clean fields explicitly rather than overwriting evidence.
- Choose charts based on analytical question, scale, and uncertainty; do not decorate away readability.
- For documents, preserve requested page/word/style constraints and verify the generated file opens correctly.
- For slides, optimize for one idea per slide, visual hierarchy, and spoken presentation rather than dense report text.
- Use the task-specific document/spreadsheet/slide/PDF workflow required by the execution environment.
