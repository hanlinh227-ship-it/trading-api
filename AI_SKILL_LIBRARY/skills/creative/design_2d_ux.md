# Skill: design_2d_ux

Covers graphic design, UX/UI, product design, design systems, branding, typography, color, layout, illustration, and product photography direction.

- Establish audience, task hierarchy, device/canvas, brand constraints, and accessibility needs.
- Build information hierarchy before decoration.
- Keep spacing, type scale, components, states, and interaction patterns systematic.
- For product images, preserve exact product geometry/material/details unless the user explicitly requests a redesign.
- Use Figma for design-system/UI work and Product Design for flows/prototypes when available and useful.
- Evaluate usability, consistency, contrast, responsive behavior, empty/loading/error states, and interaction feedback.
