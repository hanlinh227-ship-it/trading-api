# Skill: scriptwriting

Covers screenwriting, voice-over, advertising copy, hooks/retention, storytelling, children's content, YouTube scripts, and social content.

- Define audience, platform, duration, objective, voice, and call to action before drafting.
- Hooks should create a specific information/emotional gap without making claims the body cannot support.
- Maintain causal scene progression; each beat should change information, emotion, action, or stakes.
- For voice-over, write for speech rhythm rather than prose formatting.
- For advertising, connect feature -> practical benefit -> reason to believe -> offer/action.
- For children's content, favor clarity, repetition, safe understandable actions, and visual beats that can be rendered consistently.
- When converting scripts to scenes, keep narration timing and visual action synchronized.
