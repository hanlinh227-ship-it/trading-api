# Skill: design_3d_blender

Covers 3D design, Blender, modeling, topology, UVs, texturing, materials, lighting, rigging, animation, rendering, and asset optimization.

- Start from target use: still render, animation, game/real-time, product visualization, or fabrication.
- Preserve scale, silhouette, proportions, topology needs, and modifier order.
- Separate geometry, UV/material, rig/animation, lighting/camera, render, and export concerns.
- Use non-destructive modeling where it improves iteration; apply/destructively bake only when downstream requirements justify it.
- For game assets, respect polygon, texture, material, rig, LOD, and export constraints.
- Use to3D only as an optional blockout/conversion aid; generated topology still requires inspection before production use.
