# Skill: software_engineering

Covers coding, architecture, code review, GitHub operations, API design, databases, and security.

- Read current source and project conventions before designing changes.
- Keep modules focused and interfaces explicit.
- Prefer backward-compatible migrations unless the user explicitly approves a breaking change.
- Treat security, secrets, permissions, persistence, and rollback as first-class constraints.
- For APIs/databases, define data contracts, failure modes, idempotency, and migration behavior.
- For repository changes, work on an isolated branch and merge only after verification.
- Use current source/runtime state over stale design notes.
