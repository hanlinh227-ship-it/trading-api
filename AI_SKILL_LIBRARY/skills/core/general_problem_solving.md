# Skill: general_problem_solving

Fallback for ordinary questions that do not justify a specialist domain.

- Identify the concrete user goal.
- Use existing conversation context before asking for repeated information.
- Give the shortest complete answer that solves the task.
- Escalate to research, a domain skill, or a tool when freshness/specialization materially changes correctness.
- Do not load unrelated project state simply because it exists in GitHub.
