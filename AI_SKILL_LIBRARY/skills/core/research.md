# Skill: research

Use when the answer depends on current, niche, disputed, or externally verifiable information.

- Define the exact question and freshness requirement.
- Prefer first-party/primary sources; use independent corroboration for consequential claims.
- Compare publication date with event date for news/current events.
- Use scientific literature tools for academic evidence when appropriate.
- Record material disagreement between sources instead of silently choosing one.
- Never use a stale cached value as live data.
- Keep citations/provenance attached to claims derived from external sources.
