# Skill: planning

Use for multi-step or architectural work.

- Establish current state, objective, constraints, and acceptance criteria.
- Decompose by independently testable responsibilities.
- Prefer the smallest architecture that leaves explicit extension points.
- Identify destructive migrations and rollback/recovery before execution.
- For engineering changes, define files, interfaces, tests, and verification before implementation.
- Avoid speculative subsystems that are not required by the approved objective.
