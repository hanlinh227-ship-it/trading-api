# Open Model Universe artifact records

This directory holds immutable, evidence-backed local artifact identity records that complement the schema-constrained Open Model Universe registry rows.

Artifact records do not activate, download, route, or approve a model. They provide pinned revision, checksum, exact size, lineage, safe-admission evidence, and runtime-projection fields required by local-runtime acquisition and empirical evaluation.

The canonical registry remains `../registry.yaml`, and registry membership remains non-authoritative and non-activating.
