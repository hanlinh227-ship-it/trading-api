# Open Model Universe artifact identities

This directory contains immutable artifact evidence for canonical local model records.

A registry row may reference a model family and runtime contract, while the companion artifact identity pins the exact downloadable file, revision, SHA-256, byte size, quantization, lineage, and first-load safety admission evidence required by the local runtime acquisition plane.

Artifact identity does not imply runtime activation. First load remains isolated and fail-closed until runtime evidence satisfies the activation gates.
