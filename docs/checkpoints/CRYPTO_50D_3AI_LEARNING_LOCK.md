# CRYPTO 50D 3AI LEARNING LOCK

Claude + OpenAI/ChatGPT + DeepSeek are research advisers, never PASS authorities.

On every DEV failure the runner builds a DEV-only failure package. The council independently diagnoses it and proposes a new symbol-specific profile. At least 2 providers must respond. Consensus prefers agreement on strategy family + RR; otherwise the highest-confidence proposal is used only as the next research hypothesis.

Validation data is forbidden from AI prompts. A validation failure permanently rejects that frozen profile version; its validation result is append-only evidence. A new profile version must return to DEV before it can see a new unseen validation window.

Allowed RR: 1:1 or 1:2 only. Target: >=80% validation WR with the configured minimum trade gate and positive expectancy after costs. No failed window may be deleted or hidden.

Per-symbol learning lineage is mandatory: version, parent version, DEV trial IDs, council proposal, provider outputs/errors, profile hash, RR, validation IDs and final status.

The backtester alone computes trades and PASS/FAIL. AI cannot edit historical results, validation thresholds, minimum trades, costs, data, seeds, or target WR.
