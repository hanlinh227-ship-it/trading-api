# CRYPTO SYMBOL PROFILES V1

Updated: 2026-08-17 UTC+7
Purpose: every crypto symbol must be analyzed with its own linked drivers. This does NOT replace the common crypto core (BTC + breadth/regime + HTF structure + M15/M5 + anti-chase); it adds symbol-specific context and weights.

## Core rule
For every coin, analysis order is:
1. BTC direction/liquidity/risk regime;
2. whole-crypto breadth and market regime;
3. symbol-specific linked drivers below;
4. D1/H4/H1 structure + 6h/24h/72h momentum;
5. M15/M5 execution path and anti-chase;
6. fresh order flow/news only when genuinely available;
7. structural SL and realistic TP;
8. MARKET / LIMIT / NO TRADE classification.

No symbol may be reduced to a generic RSI/EMA score.
