# STACKHUB Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a zero-new-cost crypto earning orchestrator that safely aggregates passive sources and human-required microtasks without violating platform automation restrictions.

**Architecture:** A static source registry feeds a compliance gate, normalized models, ROI ranker, SQLite ledger, status exporter, and CLI. The MVP uses conservative/manual collectors unless a documented machine interface is verified. Restricted third-party tasks are discovery-only.

**Tech Stack:** Python 3.11+, standard library (`dataclasses`, `sqlite3`, `argparse`, `json`, `pathlib`, `unittest`), GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-11-stackhub-design.md`

## Global Constraints
- Zero new paid infrastructure or paid APIs.
- Never automate CAPTCHA, surveys, games, KYC, purchases, withdrawals, or anti-bot bypasses.
- Never run residential-only traffic sharing on VPS/server IPs.
- Never store wallet seeds or private keys.
- Tokens/secrets must not appear in telemetry or Git.
- Do not modify production trading services.
